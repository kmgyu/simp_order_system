## 1. 목적 및 적용 범위

실서비스 또는 공유 환경에 변경을 반영할 때 필요한 수동 점검표이다. 이 문서가 존재한다는 이유로 에이전트에게 배포 권한이 생기지 않는다.

## 2. 배포 전 체크리스트

- [ ] 배포 대상 브랜치·커밋·버전·환경을 명시했다.
- [ ] 필요한 코드 리뷰/승인을 확보했다.
- [ ] CI 및 관련 테스트가 통과했거나 예외를 공식 승인받았다.
- [ ] API/DB/설정 변경의 하위 호환성과 배포 순서를 확인했다.
- [ ] DB 마이그레이션의 영향·락·용량·백필·재실행·롤백을 검토했다.
- [ ] 필요한 백업/복구 가능성 및 복구 담당자를 확인했다.
- [ ] 배포 후 확인할 주요 기능과 관측 지표를 정했다.
- [ ] 배포 중단·롤백 판단 기준을 정했다.
- [ ] 배포 명령/접근 권한을 검증하고 **사용자 명시 승인**을 받았다.
