## 4. 의존성 및 경계 규칙

- **MUST**: 모듈 경계를 넘는 호출은 실제 존재하는 공개 인터페이스를 사용한다.
- **MUST**: 계층 간 의존 방향과 순환 참조 위험을 검토한다.
- **MUST NOT**: 요청 없이 전체 계층 구조를 변경하거나 신규 프레임워크를 도입하지 않는다.
