# ADR-0002: 재고 확정 시점과 취소 복원 정책

- Status: Proposed
- Date: 2026-10-14
- Owners: BE Domain owner (TBD)

## Context
현행 `submit_order()`는 재고 차감하지 않지만 `cancel_order()`는 복원하여 불일치를 야기한다. 선결제/현장확인 방식이 혼재하므로 재고 상태 전이를 도메인 정책으로 고정해야 한다.

## Alternatives
A. **주문 시 즉시 차감**(파일럿 계좌이체 수동확인): 현장 재고 초과판매 방지에 간단. 다만 미입금 주문이 오래 대기할 경우 재고 고갈 위험 → 취소/만료 정책 필수.
B. **주문 시 예약, 결제 승인 시 확정 차감**: 선결제에 적합하지만 예약 만료/해제 작업 및 동시성 복잡도 증가.

## Proposed Decision
P0에는 A안을 제한적으로 선택하되 미입금 만료 정책과 점주 조정(업무 승인)을 정의. PG 샌드박스 도입 시 B안 도입 여부를 별도 ADR에서 결정.

## Invariants
- 유한 재고 메뉴에서 확정 후 `stock >= 0`.
- 주문 생성과 재고 효과가 한 트랜잭션.
- 취소 시 실제 차감내역이 있는 경우에만 정확히 한 번 복원.
- 주문 실패·결제 상태 역전이에 재고 중복 변경 없음.

## Proof
TC01/TC02/TC05/TC06/TC08 + MySQL 병렬 트랜잭션·데드락 재시도 실험 통과 및 DB before/after 증거.
